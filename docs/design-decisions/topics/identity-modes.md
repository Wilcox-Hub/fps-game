# Identity, modes and naming

Generated from [current.json](../current.json). Read current rules before historical interviews.

## identity-arena-survival — Sci-fi squad arena survival

**APPROVED** · Recorded 2026-10-18

Keep the sentry-arena identity, purposeful enemies, pressure, cover and stakes. The main route moves arena to arena. Zombie theming, mindless crowds, repeated circular kiting and superhero player powers do not define this game.

Sources: [owner-arena-identity](../../../docs/design-decisions/sources.md#owner-arena-identity), [owner-pressure-wording](../../../docs/design-decisions/sources.md#owner-pressure-wording).

## identity-modes — Progression Run and Holdout

**APPROVED** · Recorded 2026-10-18

PROGRESSION RUN is the multi-arena mode, targeting a 45–60-minute successful run. HOLDOUT is the future single-arena survival mode; tune its duration later. Expose only the current playable mode for now.

Sources: [owner-arena-identity](../../../docs/design-decisions/sources.md#owner-arena-identity), [2026-10-13-naming-perks-q10](../../../docs/design-decisions/interviews/2026-10-13-naming-perks.md#2026-10-13-naming-perks-q10), [2026-10-13-naming-perks-q13](../../../docs/design-decisions/interviews/2026-10-13-naming-perks.md#2026-10-13-naming-perks-q13).

## identity-working-title — Keep IRON SUN for now

**OPEN** · Recorded 2026-10-18

IRON SUN remains the working title. Naming is open: short, industrial/in-world language, pressure/survival with some competition; explore restrained stamped lettering and a fighter-applied mark after selecting a title. None of the rejected REDUCT variations or later shortlist names is approved.
