## network-host-state — Host-owned runs and private playtest server

**APPROVED** · Recorded 2026-10-18

Keep progression/checkpoints on the active host/server. Preserve LAN and the approved free Lenovo private-server/tunnel route for remote friends. Host migration and shared Steam Cloud run state are outside this milestone. A future rented-server expansion is a separate decision; do not treat old dedicated-server deferral as cancelling the already approved Lenovo playtest.

Sources: [owner-server-direction](../../../docs/design-decisions/sources.md#owner-server-direction).

## delivery-launcher — Installed launcher and published updates

**APPROVED** · Recorded 2026-10-18

Friends get a clear Windows installer/link, installed launcher and shortcuts. Launcher downloads/verifies the game and published updates. Play opens the front end. Keep launcher, game package, server protocol and tested source identities distinct; local code edits are not automatically live updates.

Sources: [owner-launcher](../../../docs/design-decisions/sources.md#owner-launcher), [owner-lobby-direction](../../../docs/design-decisions/sources.md#owner-lobby-direction), [current-evidence](../../../docs/design-decisions/sources.md#current-evidence).

## delivery-cost — No new signing fee

**APPROVED** · Recorded 2026-10-18

Keep the launcher unsigned under the owner's current choice. No new paid signing, subscriptions or service charges without separate explicit approval. Do not disable Windows protections to hide an unsigned-app prompt.

Sources: [owner-no-signing-cost](../../../docs/design-decisions/sources.md#owner-no-signing-cost).
